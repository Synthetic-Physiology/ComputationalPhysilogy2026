# This is the repository of the elective course Computational Physiology in 2026

Students brought their own projects.

Project scientific communication:
personalized mRNA-vaccine for malignant melanoma - 2 different 3D-Models with educational videos on [cellular level](https://synthetic-physiology.github.io/ComputationalPhysiology2026/SciCom/MMOH_cellular.html) and on [molecular level](https://synthetic-physiology.github.io/ComputationalPhysiology2026/SciCom/MMOH_molecular.html). (Mariella Metzner & Olivia Hank)

Project aquagenic pruritus: interactive [Model](https://synthetic-physiology.github.io/ComputationalPhysiology2026/AquaPur/Model01.html) of how timing, dosage, and contact duration before water exposure (t = 0) modulate aquagenic pruritus with beta-alanine in arbitrary units (a.u.). (Liliana Rudolf)
