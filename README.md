# This is the repository of the elective course Computational Physiology in 2026

Students brought their own projects.

Project scientific communication:
personalized mRNA-vaccine for malignant melanoma - 2 different 3D-Models with educational videos on [cellular level](https://synthetic-physiology.github.io/ComputationalPhysiology2026/SciCom/MMOH_cellular.html) and on [molecular level](https://synthetic-physiology.github.io/ComputationalPhysiology2026/SciCom/MMOH_molecular.html). (Mariella Metzner & Olivia Hank)

Project aquagenic pruritus: interactive [Model](https://synthetic-physiology.github.io/ComputationalPhysiology2026/AquaPur/Model01) of how timing, dosage, and contact duration before water exposure (t = 0) modulate aquagenic pruritus with beta-alanine in arbitrary units (a.u.). (Liliana Rudolf)

Project Blood flow in a vascular network: The [model](https://synthetic-physiology.github.io/ComputationalPhysiology2026/BloodFlow/blood_flow_demo.html) enables the user to see how a vessel occlusion affects blood flow in adjacent vessels (Felix Schneider)

Project protein folding dependent protein protein interaction: Using interactive py3Dmol molecular models and schematic visualizations, the project illustrates how losing the C-terminal region removes a key binding interface for p47phox, impairing activation of the NADPH oxidase complex and its catalytic core (NOX2), reducing the antimicrobial respiratory burst, and linking to chronic granulomatous disease (CGD). (Magali Stecher)

Project insulin response to GLP1-agonists: A physiological glucose-insulin [model](https://synthetic-physiology.github.io/ComputationalPhysiology2026/MucleGLP1/MuscleGLP1.html) built from published study values separates the effects of GLP-1 receptor agonists into fat loss, muscle loss and direct drug actions. (Luke Gemünden)

Project Piezo simmulation: A molecular [model of Piezo1](https://synthetic-physiology.github.io/ComputationalPhysiology2026/PiezoSim/PIEZO1_Simulator.html) with and without mutations to simulate ion current in response to mechanical stimulation of a cell or a membrane patch. (Ben Seibel)
